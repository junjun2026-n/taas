# Qionghai TaaS 独立项目

???**v0.261115** ? ???????? ? [GPLv3 ??](LICENSE) ? [????](COPYRIGHT.md)

这是从主运维平台拆出的独立 TaaS 服务，包含用户注册、登录会话、角色权限、客户门户、API Key 和套餐管理。

## 启动

在项目根目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\start.ps1
```

默认地址：http://127.0.0.1:8100/taas/ ；API 文档：http://127.0.0.1:8100/docs 。管理界面采用 NiceGUI 3.18.0，REST/OpenAI API 仍由 FastAPI 提供。后端完全独立使用 PostgreSQL，连接串由 `TAAS_DATABASE_URL` 指定，默认值为 `postgresql://huitian:SET_LOCALLY_BEFORE_USE@192.168.17.127:5432/qionghai`。首次启动会自动初始化独立表并创建管理员 `admin`，密码由 `TAAS_ADMIN_PASSWORD` 指定，默认值为 `ChangeMe123!`。

## 目录

PostgreSQL 表使用独立的 `taas` schema，不访问主平台的 `public.users` 等表。已有 TaaS 账号密码保持不变；初始管理员密码仅在首次创建账号时生效。

管理员登录后默认进入后台管理，可管理用户、角色权限、渠道、模型、套餐、订单、充值、支付配置和系统设置。客户门户提供 API Key、用户独立 Base URL、套餐订单、微信/支付宝支付和兑换码功能；完整 new-api 功能差异见 `docs/taas-new-api-parity.zh-CN.md`。

- `backend/app/`：独立 FastAPI 服务、认证、权限和业务 API。
- `backend/schema.sql`：独立 PostgreSQL 结构初始化脚本。
- `frontend/`：独立门户页面（由后端直接提供静态文件）。
- `start.ps1`：Windows 启动脚本。
