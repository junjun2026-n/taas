# 模型计费

在「模型」菜单设置每个模型的输入/输出价格，单位为人民币元 / 百万 Token。免费模型也必须显式配置零价格；未配置价格的模型拒绝调用。

成功请求按上游返回的 prompt_tokens 和 completion_tokens 计算费用，四舍五入到余额精度（0.0001 元）。余额更新、密钥用量累计与日志在同一数据库事务执行，锁定用户余额防止并发扣减造成负余额。失败响应不扣费。

流式请求自动要求 stream_options.include_usage，读取 SSE 用量后结算并记录日志。若上游未提供用量，发出提示且本次不计费。当前未处理缓存 Token 和推理 Token 的独立价格。

本阶段采用调用后结算，尚未实现调用前额度预占。余额不足时返回 402；流式响应开始后，以 SSE 错误事件提示结算失败。并发请求可能已消耗上游资源却因余额不足无法结算。客户端断开、上游网络异常、缺失用量的补偿结算尚未完成。因此不能将本阶段当作完整的生产计费闭环。

配置价格不会追溯扣减历史调用，也不会自动修改现有模型价格。接口为 GET /api/admin/model-prices、PUT /api/admin/model-prices/{model}，需 keys.manage 权限。
