# 用户启用、停用与删除

拥有 `users.manage` 权限的操作员可在「用户」表格最后一列启用、停用或删除非管理员账号。ADMIN 用户名和 admin 角色均受保护，后台接口也会拒绝操作。不能停用或删除当前登录账号。

停用后立即清除登录会话，用户无法重新登录，已有 API Key 无法调用。重新启用后可重新登录，原来启用的密钥恢复可用。

删除使用逻辑删除：将账号标为 deleted、清除会话并禁用全部密钥，从用户列表移除，保留订单、充值与调用历史。删除不可通过启用恢复，原用户名仍保留。

接口：

- `PUT /api/admin/users/{user_id}/status`，请求体 `{"status":"active"}` 或 `{"status":"disabled"}`。
- `DELETE /api/admin/users/{user_id}`，逻辑删除。

上述接口需要登录及用户管理权限。
