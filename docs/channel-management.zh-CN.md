# 渠道管理

「渠道」菜单支持新增、修改、启停、删除与连接测试，需 keys.manage 权限。表格最后一列提供操作按钮。

上游 API 地址通常包含 /v1。修改时密钥留空保留原值，接口响应和表格均不返回上游密钥。模型范围按逗号分隔，保存时去重并清理空格。

连接测试向上游 /models 发起认证请求，显示模型数量和延迟；这仅验证模型列表接口，不保证每个模型能够正常生成。测试可用于停用渠道，超时为 15 秒。

排序权重较大的渠道优先被选择。非流式请求遇到网络错误或 5xx 会按权重顺序切换到下一个匹配渠道；4xx 不重试。流式请求只在建立连接前切换，已经开始输出后不切换，避免重复生成。删除需确认，历史调用日志保留但渠道关联被置空。

接口：GET/POST /api/admin/channels、PUT/DELETE /api/admin/channels/{id}、POST /api/admin/channels/{id}/test。
