# 数据库配置

管理员进入「系统配置 → PostgreSQL 数据库配置」，可设置数据库地址、端口、数据库名称、用户名、密码及 SSL 模式。

- 点击「测试连接」验证数据库是否可访问。
- 点击「保存数据库配置」会先测试连接，成功后保存至 `taas_api/config/database.json`。
- 密码留空时保留当前连接密码；配置文件包含凭据，请限制文件访问权限。
- 保存后需重启 TaaS 服务才能生效。切换数据库不会自动迁移原有用户、订单及充值数据。
- 配置读取顺序为：环境变量 `TAAS_DATABASE_URL`、本地配置文件、默认连接配置。设置环境变量时，本地保存的配置不会覆盖它。

在项目目录执行 `./start.ps1` 启动服务；如已有服务运行，请先停止原进程再启动。
