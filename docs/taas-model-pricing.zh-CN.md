# 按模型配置计费

新增或修改套餐时，可从已启用渠道的模型列表多选组合。尚未配置价格的模型仍会出现在选项中，并标记「未配置价格」；需先在本页配置价格才能保存包含它的套餐。可点击「刷新套餐模型」重新加载，原有选择会保留。

管理端「模型」页的「模型计费」表格按模型分别显示输入单价、输出单价和计费状态，单位为人民币元 / 百万 Token。选项来自已启用渠道及已经配置过价格的模型。

直接在模型所在行填写输入与输出单价，点击同一行「保存本模型」。保存后该行显示已保存的输入、输出单价，不清除其他行尚未保存的输入。未配置价格与零价格明确区分：免费模型也需要保存输入、输出单价为 0。渠道变化后点击「刷新模型与价格」（刷新会重新加载价格，请先保存编辑内容）。每个模型的价格独立保存，修改一个模型不影响其他模型。

实际调用按最终选中的模型读取 `model_prices` 价格，记录费用：

`费用 = (输入 Token × 输入单价 + 输出 Token × 输出单价) / 1,000,000`

消费日志金额保留 8 位小数；失败调用不计费。价格在请求转发前读取，之后修改价格用于后续请求。订单及 API Key 的 Token 额度仍按实际输入、输出 Token 总数消耗，费用记录用于金额统计，不会重复扣除用户钱包余额。

验证覆盖模型独立保存、不同输入输出费率、低额消费精度、零价格及失败调用费用。
