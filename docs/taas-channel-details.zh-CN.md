# 渠道详情

在管理控制台的“渠道”列表中点击“详情”，可查看：

- 渠道 ID、名称、地址、状态、权重、模型范围、创建时间及密钥是否已配置。
- 本平台记录的调用次数、成功和失败次数、输入和输出 Token、总 Token、计费金额、平均耗时、最近调用时间及按模型汇总。
- 已适配上游的实时账户余额；点击“刷新详情”重新查询。

详情接口为 `GET /api/admin/channels/{channel_id}/details`，要求 `keys.manage` 权限。接口及弹窗不返回上游密钥。

当前 DeepSeek 官方渠道通过 `https://api.deepseek.com/user/balance` 查询币种、总余额、赠送余额、充值余额及账户是否可用。用户名、邮箱等身份信息未开放查询，页面会显示说明。其他上游尚未适配余额接口时显示“暂未适配”，不会将未知余额显示为零。

平台调用统计仅包括经本平台处理并记入日志的请求，不包含在上游其他客户端的调用。平台模型定价产生的计费金额与上游实际扣费可能不同。上游查询失败不会影响平台统计的展示。
